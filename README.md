# Foldz
Foldz is a lightweight, single-file HTML5 web application that procedurally generates high-resolution, abstract wallpapers and geometric artwork directly in the browser.  
Features
 Procedural Scene Generation: Create unique compositions with customizable geometric shapes including sweep layers, soft orbs, fluid waves, dunes, concentric arcs, and organic blooms.  
 Color & Finish Controls: Choose from multiple curated color palettes, invert tones, and tweak visual parameters like edge softness, layer contrast, and procedural canvas grain.  
 Multi-Device Aspect Ratios: Render crisp wallpapers tailored for smartphones, tablets, desktops, or square displays.  
 Seed Navigation & Randomization: Instantly generate new art with a random seed or navigate back through previously generated seeds.  
 Zero Dependencies: Pure vanilla HTML, CSS, and JavaScript utilizing Canvas2D—no build steps or external frameworks required.  
 Direct Export: Export high-resolution PNG image files via browser download or system share menus.
